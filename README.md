# TaskFlow — To-Do List

A responsive JavaScript To-Do List application built with HTML, CSS, and JavaScript. TaskFlow allows users to create, manage, filter, edit, and delete tasks while automatically saving data using browser localStorage.

## 🌐 Live Demo

[Open TaskFlow](https://nishma73.github.io/taskflow-todo/)

## ✨ Features

- Create new tasks
- Mark tasks as completed
- Edit existing tasks
- Delete individual tasks
- Filter tasks by All, Active, and Completed
- Clear completed tasks
- Delete all tasks
- Persistent data using localStorage
- Dynamic DOM manipulation
- Event delegation
- Responsive mobile-friendly interface
- Empty-state interface
- Edit task modal
- Accessible form controls

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Browser localStorage
